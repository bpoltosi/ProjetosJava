# ProjetosJava

Repositório de estudos e exercícios desenvolvidos em **Java**, utilizado para praticar fundamentos da linguagem e conceitos de programação orientada a objetos.

## 🎯 Objetivos
- Praticar a sintaxe e os fundamentos de Java.
- Desenvolver lógica de programação.
- Estudar Programação Orientada a Objetos.
- Registrar exercícios e experimentos realizados durante os estudos.

## 📚 Conteúdos
- Variáveis e tipos
- Estruturas condicionais e de repetição
- Métodos
- Classes e objetos
- Encapsulamento
- Herança e polimorfismo
- Coleções
- Organização de código

## 🚧 Status
**Em desenvolvimento contínuo.**

Este repositório faz parte do meu processo de aprendizagem em Java e serve como registro da evolução prática na linguagem.

## 🧠 Sobre
Os exercícios têm finalidade principalmente acadêmica e de aprendizado. Projetos mais completos serão documentados individualmente conforme forem desenvolvidos.
